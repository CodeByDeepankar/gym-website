A modern, responsive gym website built with HTML, CSS, and JavaScript.

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, etc.)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/gym-website.git
```

2. Open the project folder:
```bash
cd gym-website
```

3. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server

# Using PHP
php -S localhost:8000
```

4. Visit `http://localhost:8000` in your browser

## 🔧 Customization

### Colors
Change the CSS variables in `style.css`:
```css
:root {
    --primary-color: #ff4d4d;      /* Main accent color */
    --secondary-color: #1a1a2e;   /* Dark background */
    --text-color: #333;            /* Main text color */
}
```

### Content
Edit `index.html` to change:
- Text content
- Images (replace Unsplash URLs with your own)
- Links
- Pricing plans
- Trainer information

### Animations
Modify `script.js` to adjust:
- Counter speed
- Scroll animations
- Form validation
- Notification timing
